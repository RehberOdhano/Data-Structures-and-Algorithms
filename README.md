# Data Structures and Algorithms

A comprehensive collection of data structures and algorithms implementations in C++, Java, and Python.

## 📁 Project Structure

### C++

- **Linked Lists**: Singly, Doubly, Circular (including Josephus Problem)
- **Stacks**: Array-based, Linked List-based, Infix to Postfix, Balanced Parenthesis
- **Queues**: Array-based, Linked List-based, Circular, Priority Queue, Double-Ended Queue
- **Trees**: Binary Search Tree
- **Graphs**: Adjacency Matrix implementation
- **Heap**: Min Heap, Max Heap
- **Sorting Algorithms**: Bubble Sort, Selection Sort, Insertion Sort, Merge Sort
- **Searching Algorithms**: Linear Search, Binary Search (iterative and recursive)
- **Graph Algorithms**: Dijkstra's Algorithm, MST (Prim's Algorithm)
- **Other**: Palindrome checker using Stack and Queue

### Java

- Arrays
- ArrayLists
- Binary Search
- Strings
- Custom Classes

### Python

- Singly Linked List
- Double-Ended Queue
- Collections: Counter, Named Tuple, Ordered Dict

## 🚀 Getting Started

Each language folder contains implementations organized by data structure or algorithm type. Navigate to the specific folder and compile/run the files as needed.

## 📝 Notes

- C++ implementations include both iterative and recursive approaches where applicable
- Some algorithms are implemented using different data structures (e.g., sorting with arrays vs linked lists)
- The project serves as a learning resource for fundamental computer science concepts
